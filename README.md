# Programming Logic

This repository documents my learning journey through a 40-hour Algorithms and Programming Logic course.

## Topics Covered

- Variables and data types
- User input and output
- Arithmetic operations
- Mathematical functions
- Relational and logical operators
- Simple conditional structures
- Compound conditional structures
- Nested conditional structures
- Multiple-choice structures
- Percentage calculations
- Numeric output formatting
- Repetition structures
- For loops
- Counters and accumulators
- Ascending and descending loops
- Custom loop steps
- Comparing and validating values inside loops

## Tools

- Visualg
- Git
- GitHub
- Scratch 3

## Repository Structure

- `01-fundamentals`: Beginner exercises organized by programming topic.
  - `01-input-output-and-calculations`: Variables, input, output, and arithmetic exercises.
  - `02-mathematical-functions`: Powers, square roots, angles, and other mathematical operations.
  - `03-relational-and-logical-operators`: Exercises using relational and logical expressions.
  - `04-conditional-structures`: Simple, compound, nested, and multiple-choice conditionals.
  - `05-repetition-structures`: Loops, counters, accumulators, custom steps, and value validation.
  - `06-procedures`: Exercises using reusable procedures.
  - `07-functions`: Exercises using functions and return values.
  - `08-arrays`: Exercises for storing and processing multiple values.
  - `09-matrices`: Exercises using data organized into rows and columns.
  - `10-scratch-exercises`: Introductory visual programming exercises created with Scratch.
  - `99-to-review`: Exercises awaiting classification or review.
